# Metanomic

Marketing website for Metanomic — a human-centered AI consulting and agent engineering company.

## Stack
- Next.js 16 App Router
- React 19 and TypeScript
- Tailwind CSS 4
- Vercel-ready deployment

## Development
Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Checks
```bash
npm run typecheck
npm run lint
npm run build
```

## Deployment
Import `geisera/metanomic` into Vercel as a Next.js project. Configure `metanomic.ai` in Vercel before changing DNS.
